# VIDA — Projeto 28

V1 do web app mobile-first do Projeto 28 da Carol.

## Estrutura
- Dashboard com Dia X/28 e Score de Constância
- Conteúdo progressivo: semanas 1, 8, 15 e 22
- Check-ins: água, sono, treino/movimento e conteúdo
- Peso, medidas e progresso
- Planner+ como adicional
- Carol Club com vagas encerradas + lista de espera
- Gym Rats como próxima fase
- PWA instalável no iPhone/Android

## Arquitetura de produção
- Front-end: Vercel
- Auth + banco + permissões: Supabase
- Pagamento: Cakto
- Webhook: Cakto → Supabase

Conteúdo V1 aprovado pela Carol. Integração técnica em andamento.
